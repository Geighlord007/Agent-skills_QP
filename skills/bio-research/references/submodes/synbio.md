# Synthetic Biology Sub-Mode

Activate when the topic involves engineered organisms, fermentation, precision fermentation, metabolic engineering, or strain construction. This sub-mode extends the generic methodology with synbio-specific threads and data sources.

## Extra threads to consider

| ID | Thread | Focus |
|----|--------|-------|
| S1 | Host chassis | *E. coli*, yeast, *Aspergillus*, *Trichoderma* suitability |
| S2 | Genetic toolbox | Promoters, markers, secretion signals, CRISPR tools |
| S3 | Fermentation scale-up | Titers, yields, productivity, DSP bottlenecks |
| S4 | Strain IP | Key platform patents, licensing landscape |
| S5 | Sustainability claims | LCA, carbon intensity, feedstock |

## Data sources

| Database | URL | Use |
|----------|-----|-----|
| PubMed | `https://pubmed.ncbi.nlm.nih.gov/` | Host strain literature |
| USPTO / EPO / Google Patents | patent search | Platform and strain patents |
| FDA GRAS Notices | `https://www.cfsanappsexternal.fda.gov/scripts/fdcc/?set=GRASNotices` | Microbial food ingredients |
| EFSA | `https://www.efsa.europa.eu/` | Novel microorganism opinions |
| JGI / NCBI Taxonomy | `https://www.ncbi.nlm.nih.gov/taxonomy` | Strain identity |
| BRENDA / UniProt | enzyme databases | Enzyme kinetics and sequences |

## Special rules

- Distinguish laboratory titer from commercial scale titer.
- Report yield on substrate and productivity when available.
- Flag whether a strain is wild-type, engineered, or proprietary.
- For filamentous fungi, note protease background and glycosylation patterns.
