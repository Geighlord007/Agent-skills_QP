# BG Info — Data-collection checklist

Use this checklist when gathering information for a new BG-info document.

## Web search targets

- [ ] Latest annual report (PDF) and CMD / Investor Day deck
- [ ] Revenue, EBITDA, EPS, ROCE targets (last 2 fiscal years + guidance)
- [ ] Division / segment structure and key brands
- [ ] Recent acquisitions, divestitures, and investments (including VC/CVC if any)
- [ ] Internal initiatives, partnerships, JVs or licensing in **precision fermentation, alternative proteins, synthetic biology**
- [ ] Leadership quotes on innovation, open collaboration, or relevant technology
- [ ] Relevant product pages (e.g., lactoferrin, whey proteins, premix, bioactive ingredients)
- [ ] Company logo (PNG/SVG) for document header
- [ ] Key investor slide (e.g., strategy map, division revenue breakdown) as image

## Sources to capture

| Source type | Typical URL pattern | Priority |
|-------------|---------------------|----------|
| Annual report | `…/investors/annual-reports` | Must have |
| CMD / Investor Day | `…/investors/presentations` | Must have |
| IR results page | `…/investors/results` | Must have |
| M&A history | `…/about/our-journey` or press releases | High |
| Product pages | `…/nutrition-solutions/…` or `…/brands/…` | High |
| Leadership quotes | Press releases, earnings call transcripts | Medium |
| Alt-protein / PF signals | Press releases, trade-media articles, patent filings | Medium |

## Quality gates

- [ ] At least one annual-report or CMD source for financials
- [ ] At least one product-page source for each brand mentioned
- [ ] Every M&A deal has a press-release or regulatory-filing URL
- [ ] Alt-protein / PF section is either populated or explicitly marked "none publicly announced"
- [ ] All URLs are reachable (spot-check 3–5)
