# Cosmetic Research Rubric

7 个维度，每个维度 5 分，满分 35 分。先检查红线，再逐维度评分。

---

## 术语定义

- **关键论断**：会影响核心判断（go/no-go）的陈述。删掉它，结论就站不住。
- **利益相关方**：对所述内容有直接商业利益（如品牌宣称自家产品效果、经销商宣传功效）。可以引用，但必须标注立场。其效果声明在无独立验证时，不得作为关键论断的唯一支撑。
- **硬事实**：可独立验证的客观陈述（PMID 论文数据、EPO 专利信息、NMPA 监管记录、公开定价等）。以一手源为准。
- **软声明**：涉及效果、因果、程度判断的陈述（"美白效果显著""市场领先"等）。来自利益相关方的软声明须有独立验证才能支撑结论。
- **证据等级**：✅ Peer-reviewed (有 PMID) > 📋 Commercial/Press release > 🔍 Unverified (微信/博客/社交媒体)

---

## 红线（一票否决）

触发任一条，总分封顶 17 分（不及格），并在评估报告中标明触发项：

1. **编造 PMID/专利号**：引用不存在的 PMID 或专利号，或捏造数据库查询结果。
2. **品牌声称冒充官方数据**：核心判断的监管/专利/临床支撑来自品牌官网而非官方数据库或 PubMed。
3. **单一利益相关方定论**：核心结论仅依赖品牌方的软声明，无任何独立验证。
4. **结论无法回溯到证据**：核心判断找不到 PMID/专利号/官方 URL 支撑，纯粹是断言。
5. **回避已知反面证据**：存在公开的强反面证据（如某国明确禁止该成分），但未提及也未回应。
6. **内部矛盾未解决**：报告不同章节对同一事实给出矛盾描述（如专利节说"A公司持有"，商业节说"B公司持有"），且未标注冲突。

## D1 — 来源可追溯性

评估报告中的数据是否可追溯到一手源。

| 子指标 | 说明 |
|--------|------|
| PMID 真实性 | 所有 PMID 是否真实存在，抽查 3–5 篇确认作者/期刊/年份与描述一致 |
| 专利准确性 | 专利申请人是否与 EPO 记录一致，不是品牌宣传 |
| 监管可查 | 各国监管状态有官方数据库支撑，不是品牌声称 |
| 来源标注完整 | 每个数据点标注了来源名称和时间，无法验证处标注 `[待补充]` |

## D2 — 证据充分性

评估支撑结论的证据是否足够、是否区分了等级。

| 子指标 | 说明 |
|--------|------|
| 交叉验证 | 关键数据点是否有 ≥2 个独立来源 |
| 证据分级 | 是否区分了同行评审/商业宣传/未验证来源，且分级正确 |
| 临床数据完整 | 临床研究的样本量、研究时长、主要结果等关键参数是否与原始论文一致 |
| 时间线准确 | 研究完成年份 vs 论文发表年份 vs 产品上市年份是否清晰区分 |

## D3 — 事实与声称分离

评估报告是否让读者清楚区分什么是已验证事实、什么是品牌声称。

| 子指标 | 说明 |
|--------|------|
| 品牌声称标注 | 品牌来源的效果声明是否标注了"来源为利益相关方" |
| 官方 vs 品牌 | 监管/专利信息是否以官方数据库为准，而非品牌官网 |
| 不确定性标注 | 证据不足处是否标注了 `⚠️ 待核实` 而非写成确定结论 |
| 未公开信息 | 未公开披露的商业条款（投资金额等）是否明确提示 |

## D4 — 结构完整性

评估报告是否覆盖了完整的研究维度。

| 子指标 | 说明 |
|--------|------|
| 基本骨架 | 是否具备：基本信息/机理/临床/商业/监管/机会与风险/待验证事项 |
| 空白维度 | 是否有 Thread 返回"无数据"却未体现在报告中 |
| 参考文献完整 | 所有引用是否有可追溯来源，无死链 |
| 首尾呼应 | 执行摘要的结论是否与正文分析一致 |

## D5 — 竞争与市场洞察

评估报告是否提供了超越信息堆叠的市场判断。

| 子指标 | 说明 |
|--------|------|
| 竞品对比 | 是否与同功效主流成分做了机制/优劣势对比 |
| 市场定位 | 是否明确了该成分的差异化定位 |
| 品牌现状判断 | 是否判断了现有品牌的市场状态（活跃/退出/萎缩），而非仅列举 |
| 机会与风险 | 是否给出了具体的机会点和风险点，而非泛泛而谈 |

## D6 — 监管准确性

评估各国监管状态是否准确、是否有官方数据库支撑。

| 子指标 | 说明 |
|--------|------|
| 中国 NMPA | 是否查询了《已使用化妆品原料目录》，而非假设 |
| 美国 FDA | 是否正确描述了 FDA 的监管方式（非预批） |
| 欧盟 CosIng | 是否实际查询了 CosIng 数据库 |
| 韩国/日本 | 是否查询了对应官方数据库 |
| 准入评估 | 各市场的合规成本和准入门槛是否合理估算 |

## D7 — 可操作性

评估报告是否从分析落到了可指导决策的产出。

| 子指标 | 说明 |
|--------|------|
| 适用公司类型 | 是否明确指出了什么类型的公司适合进入 |
| 市场优先级 | 是否给出了先切入哪个市场的建议 |
| 下一步行动 | 是否列出了具体的待验证事项和行动项 |
| 前提条件 | 建议是否标注了前提条件（如"如果韩国渠道可用"） |

---

## 评分标准

| 表现 | 分值 |
|------|------|
| 全面达标，无明显问题 | 5 |
| 基本达标，有少量瑕疵 | 4 |
| 部分达标，有明显但不致命的问题 | 3 |
| 问题较多，影响报告可信度 | 2 |
| 严重不足 | 1 |
| 完全缺失 | 0 |

## 总分解释

| 总分 | 判定 |
|------|------|
| 30-35 | 可直接用于决策场景 |
| 24-29 | 强初稿，需少量修订 |

| < 17 | 不具备使用条件，或已触发红线 |
