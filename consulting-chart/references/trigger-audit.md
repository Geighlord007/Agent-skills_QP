## 2 覆盖结论

- **已覆盖 19 条语法**:顺序桥接(含分段)、总额划分桥、趋势组合、甘特、分层构成、龙卷风、情景对比、漏斗、棒棒糖、2×2、华夫、华夫小倍数、点带、热力、Mekko、斜率、雷达、等值区域图、流向地图。对应样张里的"财务对账 + 趋势 + 排期 + 构成 + 敏感性 + 情景 + 转化 + 排名 + 矩阵 + 分布 + 关系 + 双维构成 + 起点终点 + 地理/流向"场景。
- **注册表 36 条**:其余 17 条按关系指纹登记为 planned,覆盖 01 的对比、构成、趋势、分布、关系、流程、战略、地理八类。
- **缺口**:样张与报告的词汇已全部覆盖;planned 项(桑基、网络、饼图等)不在本次审计范围。

## 3 未触发时的行为

用 `sankey-gate` 实测:三节点、两连接的端点校验通过,识别为 sankey,匹配到桑基图语法后渲染器未实现,流水线报错停止。这一门槛保证关系成立但渲染器缺失时不会退化成一幅错误的图。

## 4 触发逻辑的现状与风险

`detect()` 只看数据结构,不依赖标题或文件名:

| 数据特征 | 判定 |
|---|---|
| `schedule` | 甘特 |
| `years` + `revenue` | 趋势组合 |
| `baseline` + `levers` | 总额划分桥 |
| `columns`(含 delta) | 顺序桥接 |
| `snapshots` | 构成 |

风险:同一份数据可能同时满足多种形态(例如带年份的构成数据既可画组合图也可画堆叠时序)。当前用固定优先级判定;更稳的做法是按 brief 的读者问题加权,而不是只看数据结构。这一点留作下一版。
